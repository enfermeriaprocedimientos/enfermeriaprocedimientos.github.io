# Biblioteca de Enfermería

Web pública: https://enfermeriaprocedimientos.github.io/procedimientos-enfermeria/

Biblioteca de consulta de guías y procedimientos de enfermería, sin registro.
El contenido publicado se consulta desde Supabase al abrir la web; editar una guía
en la plataforma editorial no requiere volver a publicar este repositorio.

Este repositorio contiene únicamente el cliente web compilado y sus recursos públicos.
No contiene el panel administrativo, copias de seguridad, archivos de configuración
privados, credenciales administrativas, claves de Firebase ni datos de cuentas.
La configuración publicable de Supabase forma parte del cliente y su acceso está
limitado por las RPC y permisos del backend.

Los favoritos y las marcas de lectura se guardan en el navegador de cada dispositivo.
Esta versión muestra los avisos mientras la biblioteca está abierta; no registra el
dispositivo para recibir notificaciones con el navegador cerrado. La opción de añadir
a la pantalla de inicio no garantiza funcionamiento sin conexión.

Los reproductores de YouTube y las imágenes externas necesitan acceso a sus proveedores.
Consulta siempre los protocolos y procedimientos internos de tu centro sanitario.

En iPhone: abrir el enlace con Safari y utilizar Compartir → Añadir a pantalla de inicio
si se desea un acceso directo con el icono de la biblioteca.

Contacto: enfermeriabiblio@gmail.com
